4. Detalhamento Técnico dos Épicos

BINTER-EP-01 P0 - Crítica

FX Orchestrator & State Machine: Implementação do orquestrador de transações cambiais baseado em AWS Step Functions e microsserviços em AWS EKS. Garante consistência transacional eventual e processamento tolerante a falhas com Redis de baixa latência para garantir chaves de idempotência.

BINTER-EP-02 P1 - Alta

Integração Core EUA (Finxact): Customização do Core Finxact utilizando sua API REST para gerenciar sub-posições por moedas na mesma conta depósito. Implementação das lógicas transacionais exclusivas do mercado americano para hold e liquidação contábil nativa.

BINTER-EP-03 P1 - Alta

Integração FX & Tazapay: Gateway de pagamento internacional integrado para cotações e liquidações instantâneas. O sistema consome as APIs de checkout cross-border e trata os webhooks assíncronos de conciliação de envio de fundos.

BINTER-EP-04 P1 - Alta

Motor de Remessa Interna: Processamento do fechamento de câmbio nacional e da remessa da conta BR para a Conta Global EUA do próprio cliente, registrando os contratos de câmbio junto ao Banco Central do Brasil em conformidade legal.

BINTER-EP-05 P2 - Média

Motor de AML & Compliance: Sistema de triagem de segurança em tempo real das transações contra listas restritivas internacionais (OFAC, PEP, etc.) e limites operacionais individuais baseados no perfil tributário declarado do cliente.

BINTER-EP-06 P2 - Média

Autorização de Cartão de Débito: Adaptação do motor autorizador de cartões do Banco Inter para roteamento de transações em EUR vindas diretamente das redes de cartões, debitando preferencialmente o saldo disponível da sub-posição da moeda europeia.

Épico BINTER-EP-02: Integração Core EUA (Finxact) (SCRUM-2)

Responsável por adaptar a conta corrente americana (Core Finxact) para suportar sub-ledgers multi-moeda e interações transacionais complexas.

Principais Funcionalidades

  • Sub-posições Cambiais (Sub-Ledgers): Criação de partições lógicas para saldos em EUR na mesma conta mestre do cliente em USD.
  • Modos de Transação do Core Finxact:
    • Mode 4 Hold (Bloqueio): Reserva fundos em USD correspondentes à cotação aceita para evitar double-spending enquanto a perna externa SEPA liquida.
    • Mode 2 Post (Postagem): Efetivação do débito após confirmação de recebimento final do webhook de pagamento.

Benefícios de Design

Ao realizar holds temporários, o banco reduz a zero o risco de flutuação cambial interna ou de inconsistência de saldos, permitindo que a conta global opere com a agilidade de um banco local.

[BINTER-EP-01] FX Orchestrator & State Machine

Fase 05: Documento Técnico do Épico de Engenharia Core (Banco Inter)

1. Valor de Negócio & Escopo

Este épico abrange o desenvolvimento do orquestrador de câmbio transfronteiriço. Esse microsserviço garante a consistência eventual e gerencia o ciclo de vida de cada operação usando o padrão de microarquitetura Saga Orquestrado.

  • Garantia de Idempotência: Redis cache para armazenamento distribuído temporário de chaves transacionais.
  • Prevenção de Perdas: Mecanismos automáticos de compensação (re-crédito ao cliente) em caso de falha nos gateways de liquidação globais.

2. Arquitetura de Referência e Tecnologias

O ecossistema é projetado sob os pilares de alta resiliência e escalabilidade horizontal automática na nuvem AWS do Banco Inter:

  • Orquestrador de Fluxo: AWS Step Functions coordenando os microsserviços.
  • Camada de Computação: Microsserviços Spring Boot empacotados em containers Docker rodando em nós do AWS EKS (Kubernetes).
  • Armazenamento e Lock: Redis Enterprise no cluster para controle idempotente de concorrência com TTL de 15 minutos.
  • Eventos Assíncronos: Apache Kafka para envio das transições de estado para o Data Lake e canais de notificação push do app cliente.

3. Lógica do Saga Orquestrado (Exemplo de JSON de Definição)

O AWS Step Functions utilizará o Amazon States Language (ASL) para orquestrar as APIs. Exemplo simplificado de fluxo:

{
  "Comment": "AWS Step Function Orquestrador de Câmbio",
  "StartAt": "VerificarIdempotencia",
  "States": {
    "VerificarIdempotencia": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:us-east-1:123456789:function:check-idempotency",
      "Next": "HoldFundosFinxact"
    },
    "HoldFundosFinxact": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:us-east-1:123456789:function:hold-finxact-funds",
      "Catch": [
        {
          "ErrorEquals": ["States.ALL"],
          "Next": "CompensarCancelamento"
        }
      ],
      "Next": "PayoutTazapay"
    },
    "PayoutTazapay": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:us-east-1:123456789:function:payout-tazapay-gateway",
      "Catch": [
        {
          "ErrorEquals": ["States.ALL"],
          "Next": "CompensarHold"
        }
      ],
      "End": true
    },
    "CompensarHold": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:us-east-1:123456789:function:release-finxact-hold",
      "Next": "CompensarCancelamento"
    },
    "CompensarCancelamento": {
      "Type": "Fail",
      "Cause": "Falha na execução e processamento da transação de câmbio",
      "Error": "TransacaoFalhou"
    }
  }
}

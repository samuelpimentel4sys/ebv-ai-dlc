Épico 02 - Alta (P1)

BINTER-EP-02: Integração Core EUA (Finxact)

Gestão e liquidação de sub-posições cambiais multi-ledger diretamente no Core Bancário Finxact.

Descrição e Objetivos

Este épico trata do mapeamento, configuração e atualização da arquitetura multimoeda no Finxact (Core dos EUA). Ele lida com os bloqueios temporários de saldos em USD (Mode 4 Hold) até que o parceiro de payout confirme o recebimento do Euro na Europa, e a subsequente liquidação final (Mode 2 Post).

Requisitos Técnicos Principais

  • Mapeamento das APIs nativas do Core Finxact para criação de sub-ledger de balanço em EUR.
  • Desenvolvimento de endpoints seguros para consulta e criação de "Hold" transacionais em tempo de conversão.
  • Sincronização de saldos em tempo real com barramento Apache Kafka interno do Banco Inter.
  • Registro de logs contábeis robustos no formato padrão para auditoria americana (FINRA).

Chave de Homologação Jira

Mapeado no board padrão do Jira como: SCRUM-2
